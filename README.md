# 🐍 Learning Python from Scratch

This repository documents my journey of mastering Python programming from the ground up as a **1st-year Electrical and Electronics Engineering (EEE)** student. 

The primary focus is building strong programming fundamentals, developing algorithmic problem-solving skills, and preparing a solid foundation for future engineering applications such as numerical analysis, circuit modeling, and scientific computing.

---

## 🎯 Objectives
- Master core Python syntax and paradigms (I/O, flow control, functions, and recursion).
- Understand standard libraries (`sys`, `math`, etc.) and essential data structures.
- Implement and document algorithmic solutions to textbook and course problem sets.
- Build discipline in clean coding, version control, and modular software design.

---

## 📂 Repository Structure
- `01-basics/` &mdash; Syntax fundamentals, standard I/O, data types, and command-line arguments.
- `02-conditionals-and-loops/` &mdash; Control flow structures, iteration, and logic.
- `03-functions-and-modules/` &mdash; Modular code design, scope, and recursion.
- `04-data-structures/` &mdash; Lists, tuples, sets, and dictionaries.
- `05-engineering-applications/` &mdash; Numerical algorithms, math models, and physics-oriented scripts.
